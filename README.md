# CSUSM-Capstone-Smart-Glasses-For-Accessibility

Project Abstract

This project is known as “Smart Glasses for Accessibility”. It involves a pair of smart glasses with an XR application that allow the glasses to read and interpret text, analyze the wearer’s environment, give audio-based feedback, and help provide navigation when walking or doing daily activities.

These types of smart glasses are intended for blind and low-vision wearers who would greatly benefit from audio-based feedback as the glasses scan a variety of objects, and can even warn the wearer if they are about to hit any objects, such as a wall.

One of our main objectives is to create an XR software application that will be compatible with a pair of AI smart glasses. In addition, we are looking to have our application work with AI models so that the system can give appropriate responses to the wearer.

We hope that this project will be of great assistance to blind and low-vision users, helping them navigate daily life and make their lives easier.
